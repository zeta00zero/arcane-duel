# Songs of the Symphony - browser prototype (v0.1, private)

Open `index.html` through any static web server (GitHub Pages works as-is). For local testing use
`python3 ../tools/serve.py` (it supports HTTP Range, which song previews need to seek).

## Controls (keyboard)
| Action | Keys |
|---|---|
| Move (left/right + depth up/down) | Arrow keys or WASD |
| Light attack | J |
| Heavy attack | K |
| Ultimate (when the Song Meter is full) | L |
| Pause | P or Esc |
| Menus / dialogue | Mouse, or Up/Down + Enter. Esc = back / skip |

Combos: J-J-J, J-J-K (finisher), K-K (kick into a launcher; juggle with more hits).

| File | What it is |

| `assets/audio/hibiki_song2.mp3` | Song 2 |
| `assets/audio/hibiki_song3.mp3` | Song 3 |

| `assets/video/hibiki_transform.mp4` | Transformation video |
| `assets/video/hibiki_ultimate.mp4` | Ultimate move video |

Song titles, preview start time and preview length are in `js/data/characters.js` (`songs:`). Want more songs?
Add another line there. The phrase text shown on screen is `transform.phraseText`.
Use MP4 (H.264 + AAC) for the videos so every browser plays them.

## Where things live
- `js/data/characters.js`: heroes (portraits, sprites, stats, moves/combos, transformation, ultimate, songs) and Noisy enemy stats. **A new hero is added with data only.**
- `js/data/missions.js`: missions, VN dialogue (story text) and waves.
- `js/data/sprite_meta.js`: generated by `tools/build_art.py`; don't edit by hand.
- `js/input.js`: input abstraction. Touch buttons can be added later with `Input.bindButton(el, 'light')`.
- `js/audio.js`: every sound goes through here, so the Options volume sliders (Master / Music / Voice-Video / Effects) apply everywhere.
- `js/game.js`: engine and scenes (Title, Missions, Songs, VN, Transform, Fight).
- `assets/img/`: art. Sprite sheets are `hibiki_sheet.png` (transformed), `hibiki_uniform_px.png` (uniform idle), and `noisy_*.png`.

Debug: add `?god=1` to the URL to make Hibiki take no damage.
